# Antigravity Smart RTL Patcher

**Read and write naturally in Persian, Arabic, and Hebrew, without disrupting English or code.**

A right-to-left and typography patch for the [Antigravity](https://antigravity.google/) desktop app and **Antigravity IDE** (VS Code Edition).

Antigravity RTL adds seamless Right-to-Left (RTL) support and typography controls to **Antigravity (Standalone App)** and **Antigravity IDE** (VS Code Edition). It adjusts text direction naturally as you type and read, while keeping code blocks, terminal, and editors left-to-right.

## Features

- **Supports Both Antigravity & Antigravity IDE**: Smart auto-detection or interactive selection for both standalone Antigravity and the VS Code-based Antigravity IDE.
- **Natural text direction:** Chat, input fields, and agent views adapt dynamically. Use **Force RTL** when you want everything right-aligned.
- **Code & Terminal stay LTR**: Code blocks, Monaco editor, and terminal remain left-to-right with customizable code fonts.
- **Typography your way:** Choose separate fonts for Persian/Arabic, English, and Code. Vazirmatn is embedded offline; font size and line height can be adjusted live.
- **Persian Keyboard Fix**: Maps `Shift + 2` to type `@` instead of `٬` on Persian keyboard layouts.
- **Quick controls:** Title-bar menu in Standalone App and UI widget in IDE, toggleable via `⌥R` on macOS / `Alt+R` on Windows and Linux.

Settings are saved in `~/.antigravity-rtl.json` and restored when you reopen the app.

## Install

Follow the steps for your operating system. Node.js **22.12 or newer** is required; you don't need to clone this repository.

> **Before running the patch:** Close Antigravity / Antigravity IDE if open.

### macOS

1. Node.js must be installed (`brew install node` or from [nodejs.org](https://nodejs.org/)).
2. In Terminal, run:

   ```bash
   npx antigravity-rtl
   ```

3. If you see *Permission Denied*, enable **App Management** for your terminal in **System Settings → Privacy & Security → App Management**, then run the command again.

### Linux

1. Node.js must be installed (`sudo apt install nodejs npm`).
2. In a terminal, run:

   ```bash
   sudo npx antigravity-rtl
   ```

*(If your Antigravity IDE is in user directories like `~/Downloads`, `sudo` is not needed: `npx antigravity-rtl --ide`)*

### Windows

1. In PowerShell (Run as Administrator), run:

   ```powershell
   npx antigravity-rtl
   ```

### CLI Options & Flags

| Command | Description |
| :--- | :--- |
| `npx antigravity-rtl` | **Auto-detect & patch**: patches both Antigravity & Antigravity IDE if found, or the installed one |
| `npx antigravity-rtl --ide` | Directly patch Antigravity IDE only |
| `npx antigravity-rtl --app` | Directly patch Antigravity Standalone App only |
| `npx antigravity-rtl --restore` | Revert changes and restore original backups for all detected apps |
| `npx antigravity-rtl --restore --ide` | Revert changes and restore Antigravity IDE only |
| `npx antigravity-rtl --restore --app` | Revert changes and restore Antigravity Standalone App only |
| `npx antigravity-rtl --path "/path/to/app"` | Specify a custom installation directory or app.asar |

<a id="uninstall"></a>

## Uninstall / Revert the patch

Quit the app(s) and run with `--restore` (or `-r`):

```bash
npx antigravity-rtl --restore
```
*(Or specify `--ide` or `--app` to restore only one: `npx antigravity-rtl --restore --ide`)*

## How it works

1. **Detection**: Automatically locates your Antigravity app (`app.asar`) or Antigravity IDE (`resources/app`).
2. **Safe Backup**: Creates backups (`.bak` / `.rtl-bak`) before any file modification.
3. **Smart Injection**:
   - **Antigravity App**: Injects the RTL engine into core logic (`utils.js`) and repacks `app.asar`.
   - **Antigravity IDE**: Injects an isolated hook (`antigravity-rtl-main.js`) into `out/main.js` targeting workbench and agent windows.
4. **Offline Font**: Embeds the beautiful Vazirmatn Variable font locally.

## فارسی

**خواندن و نوشتن فارسی در Antigravity و Antigravity IDE، بدون به‌هم‌ریختن متن انگلیسی و کد.**

Antigravity RTL یک ابزار خط فرمان برای افزودن پشتیبانی راست‌به‌چپ و تنظیمات تایپوگرافی به هر دو نسخهٔ **Antigravity (اپلیکیشن مستقل)** و **Antigravity IDE (نسخه مبتنی بر VS Code)** است.

### امکانات

- **پشتیبانی دوگانه (Antigravity و Antigravity IDE)**: شناسایی خودکار یا منوی تعاملی برای انتخاب بین نسخه مستقل و IDE.
- **جهت‌دهی خودکار متن:** چیدمان پیام‌های چت، ورودی‌ها و پرامپت‌ها بر اساس زبان متن راست‌چین یا چپ‌چین می‌شود.
- **ایزولاسیون کد و ترمینال:** بلوک‌های کد، ادیتور Monaco و محیط ترمینال با پشتیبانی از انتخاب فونت کد کاملاً چپ‌چین (LTR) باقی می‌مانند.
- **تایپوگرافی دلخواه:** تعیین فونت مجزا برای متون فارسی/عربی، انگلیسی و کد به همراه فونت توکار **وزیرمتن (Vazirmatn Variable)** بدون وابستگی به اینترنت.
- **حل مشکل کلید `@`:** اصلاح میانبر `Shift + 2` روی کیبورد فارسی برای تایپ مستقیم علامت `@`.
- **دسترسی سریع:** پنل تنظیمات در برنامه و کلید میانبر `⌥R` در مک یا `Alt+R` در ویندوز و لینوکس.

### گزینه‌ها و فلگ‌های خط فرمان

| دستور | توضیحات |
| :--- | :--- |
| `npx antigravity-rtl` | **تشخیص و پچ خودکار**: در صورت وجود هر دو برنامه، هر دو پچ می‌شوند؛ در غیر این صورت برنامهٔ موجود پچ می‌شود |
| `npx antigravity-rtl --ide` | فقط پچ مستقیم نسخهٔ Antigravity IDE |
| `npx antigravity-rtl --app` | فقط پچ مستقیم نسخهٔ مستقل Antigravity |
| `npx antigravity-rtl --restore` | بازگردانی به نسخه اصلی برای تمام برنامه‌های شناسایی‌شده |
| `npx antigravity-rtl --restore --ide` | فقط بازگردانی Antigravity IDE به نسخه اصلی |
| `npx antigravity-rtl --restore --app` | فقط بازگردانی نسخه مستقل Antigravity به نسخه اصلی |
| `npx antigravity-rtl --path "/path/to/app"` | مشخص کردن مسیر دلخواه نصب برنامه |

### نصب

1. **مک (macOS):**
   ```bash
   npx antigravity-rtl
   ```
   *(در صورت خطای دسترسی، تیک App Management را در تنظیمات حریم خصوصی مک برای ترمینال فعال کنید)*

2. **لینوکس (Linux):**
   ```bash
   sudo npx antigravity-rtl
   ```

3. **ویندوز (Windows):**
   PowerShell را با دسترسی Administrator باز کرده و اجرا کنید:
   ```powershell
   npx antigravity-rtl
   ```

### بازگردانی به حالت اولیه (Uninstall)

برنامه‌ها را ببندید و فلگ `--restore` (یا `-r`) را اجرا کنید:

```bash
npx antigravity-rtl --restore
```
*(یا برای بازگردانی فقط یک برنامهٔ خاص: `npx antigravity-rtl --restore --ide`)*
